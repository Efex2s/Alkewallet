# Palette Journal

## 2024-04-12 - TextInputLayout for better accessibility and UX
**Learning:** Using `TextInputLayout` with `TextInputEditText` provides a much better user experience in Android by offering floating hints, built-in error states, and easy implementation of the password visibility toggle. This is more accessible than plain `EditText` as it maintains the hint even after the user starts typing.
**Action:** Prefer `TextInputLayout` for all form-like inputs in this app to ensure consistency and a high standard of UX/accessibility.
