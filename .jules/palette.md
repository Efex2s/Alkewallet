## 2026-07-09 - Refactoring Navigation Anti-patterns
**Learning:** Using EditText for navigation items is a significant UX flaw as it triggers the soft keyboard and text selection. TextView with selectableItemBackground is the correct semantic and functional choice.
**Action:** Always use TextView or dedicated list items for navigation menus to ensure a smooth, keyboard-free experience.
