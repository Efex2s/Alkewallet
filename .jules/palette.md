## 2025-05-14 - Semantic Color Coding for Financial Transactions
**Learning:** Color-coding financial amounts (green for income, red for expenses) significantly improves the scanability and immediate comprehension of transaction lists, providing a clear visual mental model for the user's financial status.
**Action:** When displaying transaction lists or account balances, always use semantic color coding to distinguish between positive and negative flow.

## 2025-05-14 - Interactive Icon Feedback and Accessibility
**Learning:** Providing visual ripple feedback (`selectableItemBackgroundBorderless`) and accessibility descriptions (`contentDescription`) for header icons (Profile, Notifications) is essential for a polished and inclusive user experience, as these elements are often the primary navigation or information nodes.
**Action:** Ensure all interactive icons have both visual state feedback and meaningful screen reader descriptions.
