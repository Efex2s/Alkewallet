## 2026-02-25 - [Improving scannability with semantic colors]
**Learning:** Replacing visual distortions like `textScaleX` with semantic color coding (e.g., green for income, red for expenses) improves both readability and accessibility without sacrificing clarity.
**Action:** Always favor color and clear typography over stretching or scaling text for emphasis.

## 2026-02-25 - [Interactive visual feedback for ImageViews]
**Learning:** Non-button elements like `ImageView` that act as buttons need explicit background ripples (e.g., `?attr/selectableItemBackgroundBorderless`) to provide the "delight" and feedback users expect from modern mobile interfaces.
**Action:** Ensure all clickable elements have an appropriate ripple or highlight state.
