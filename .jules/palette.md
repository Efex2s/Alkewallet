# Palette UX Journal

## 2026-03-30 - Visual Symmetry and Icon Consistency in Profile Lists
**Learning:** In navigation lists where items display icons on both ends (e.g., action icon on the start and chevron arrow on the end), omitting an icon on one item creates an uneven visual weight and disrupts user scanning flow. Users instinctively look for visual anchors across menu rows.
**Action:** When working with list menus or settings options, ensure all rows maintain consistent leading and trailing iconography to preserve visual balance and cognitive scanning rhythm.
