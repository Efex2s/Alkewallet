## 2025-01-24 - Accessibility and Input Polish
**Learning:** Combining basic accessibility (contentDescription, importantForAccessibility) with platform-specific UX optimizations (autofillHints) provides a high-impact, low-effort improvement that significantly enhances usability for both screen reader users and general users.
**Action:** Always check for missing autofillHints in form-heavy mobile applications and ensure all interactive ImageViews have either a contentDescription or are explicitly marked as decorative.
