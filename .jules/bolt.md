## 2026-02-01 - Optimize Splash Screen and Reduce APK Size
**Learning:** Found a hardcoded 3000ms delay in `Splash_Screen.java` that was severely impacting the Time to Interactive (TTI) metrics of the app. In addition, instantiating the `Handler` without an explicit `Looper` causes thread-safety issues and uses deprecated API patterns. Removing unreferenced large resource assets like `circular.png` (~824KB) results in a lighter, faster building, and faster installing APK package.
**Action:** Always audit startup sequences for unnecessary hardcoded delays, ensure Handler instances explicitly bind to the main Looper to prevent crashes, implement proper lifecycle cleanup in `onDestroy()` to prevent activity context memory leaks, and routinely audit/prune large unused media assets.
