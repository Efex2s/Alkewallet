# Bolt's Performance Journal

## 2026-06-13 - Optimize Splash Screen startup delay
**Learning:** A 3-second splash screen delay is unnecessarily long and negatively impacts the user experience by delaying access to the main app functionality. Reducing this delay to 1 second provides a much snappier feel while still allowing the brand to be visible.
**Action:** Always prefer shorter splash screen durations (1000ms or less) unless there is a heavy initialization process that must be completed.
